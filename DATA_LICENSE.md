# Данные и условия использования

Источник: **СберИндекс / ПАО Сбербанк**, муниципальный набор данных Data Sense, используемый в конкурсе исследовательских проектов СберИндекса. Потребительские расходы охватывают период с января 2023 по декабрь 2024 года. Транспортные расстояния и доступность рынков приведены по состоянию на 31 декабря 2024 года согласно описанию источника.

Файлы `consumption.parquet`, `connection.parquet` и `market_access.parquet` включены без изменений из официального архива `hackathonlicence.zip`. Их контрольные суммы содержатся в `results/data_audit.json`.

Лицензия исходного набора: **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**. Документ источника сохранён в `data/raw/Данные_СберИндекс_лицензия.pdf`. [Полный текст лицензии](https://creativecommons.org/licenses/by-sa/4.0/legalcode.ru).

Производные данные, таблицы и визуализации на основе набора распространяются по CC BY-SA 4.0 с указанием источника. Выполнены следующие преобразования: отбор полной панели, расчёт долей и темпов изменения, стандартизация, кластеризация, агрегирование и проекция PCA. Выводы исследования принадлежат проекту; СберИндекс их не подтверждал.

При повторном использовании сохраняются атрибуция, ссылка на лицензию и указание сделанных изменений. Код проекта распространяется отдельно по MIT.

Файл `data/labels/municipal_names.csv` содержит справочные ID и названия из открытого GeoJSON проекта [YuliyaTorgasheva/spo_map](https://github.com/YuliyaTorgasheva/spo_map). Геометрия и код этого проекта в репозиторий не включены. Справочник используется для подписей; независимая проверка соответствия административным границам исследуемого периода не проводилась. Источники и дата получения указаны в `SOURCES.md`.
