# Муниципальные траектории

Динамическая сеть сходства потребления в муниципалитетах России. Исследование для номинации «Кластеризация» конкурса СберИндекса.

На данных СберИндекса за 2023–2024 годы построены 12 месячных сетей, объединяющих 2 016 муниципалитетов. Территории сопоставляются по структуре расходов, их относительному уровню и годовым темпам изменения. Анализ показывает состав групп, переходы между ними и чувствительность этих переходов к параметрам кластеризации.

## Результаты

Leiden выделяет три крупных профиля потребления. В декабре 2024 года в них входят 1 098, 610 и 308 территорий. Разделимость профилей невысока: средний silhouette за октябрь–декабрь составляет 0,120.

Из 2 653 смен кластерных меток 49 событий в 40 территориях соответствуют условиям сохранения новой группы, поддержки при изменении параметров и величины сдвига признаков. Эти события образуют список для дальнейшего изучения. Число отобранных событий зависит от порогов фильтра.

Среднегодовая месячная доля маркетплейсов выросла во всех муниципалитетах панели; медианный прирост составил 4,10 процентного пункта. В декабрьской сети 49,94% связей с известным дорожным расстоянием соединяют центры, удалённые более чем на 1 000 км.

В сравнении 24 конфигураций лучшую совокупную оценку получил K-means с шестью группами: 0,784. Лучший допустимый вариант Leiden набрал 0,724 и выбран для анализа сообществ сети. Результаты обеих моделей включены в отчёт.

## Воспроизведение расчётов

Расчёт проверен на Python 3.12.14 под Linux. Требуется около 4 ГБ свободной оперативной памяти. В использованной среде полный запуск занял около 154 секунд при ограничении линейной алгебры двумя потоками.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m src.pipeline --config configs/default.json
```

В Windows окружение активируется командой `.venv\\\\\\\\Scripts\\\\\\\\activate`.

Повторный расчёт с сохранением опубликованных результатов в исходном каталоге:

```bash
python -m src.pipeline --config configs/reproduce.json
python -m src.verify\\\\\\\_reproduction
```

Конфигурация задаёт периоды настройки, параметры моделей и пороги отбора событий. Исходные данные находятся в репозитории; после установки зависимостей расчёт выполняется локально. Два запуска в одной программной среде совпали по девяти таблицам и семи массивам с допусками `rtol=1e-10`, `atol=1e-12`.

## Сборка отчёта и страницы

```bash
python -m pip install -r requirements-report.txt
python -m src.publish
```

Команда строит диаграммы и HTML по таблицам и массивам в `results/`, затем формирует PDF из `reports/Report\\\\\\\_RU.md`. Интерпретация в Markdown и презентация относятся к опубликованной конфигурации исследования. При изменении данных или модели их текст необходимо пересмотреть.

## Область интерпретации

Показатели СберИндекса описывают модельные оценки средних безналичных расходов жителей. Доходы населения, оборот местной торговли и совокупный объём расходов страны выходят за рамки этих измерений. Суммы приведены в номинальных рублях, муниципалитеты имеют одинаковый вес.

Связи сети отражают сходство экономических признаков. Дорожные расстояния и доступность рынков на конец 2024 года используются для ретроспективного сопоставления. Координаты PCA представляют проекцию пространства признаков. Названия территорий взяты из вторичного справочника; ключом данных служит `territory\\\\\\\_id`.
